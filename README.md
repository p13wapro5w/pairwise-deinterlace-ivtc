# pairwise-deinterlace-ivtc

隔行素材在快速横摇时出现梳齿，场序按文件头猜，顶部场和底部场搞反后运动方向倒置；动检阈值固定，慢速平移被误判为静止场，画面一半清楚一半锯齿；24p 装 60i 的 cadence 没识别，逐帧去隔行把电影感抹成视频感；字幕和台标被当作运动区域，文字边缘每帧抖动；可变帧率素材的时间戳不连续，场配对错位后音画不同步；10bit 素材在 8bit 中间缓冲里处理，渐变出现 banding；场景切换处动检跨切镜，上一镜的场被拉进新镜；GPU 和 CPU 路径的场序约定不同，预览与导出结果不一致；降噪在去隔行前做，梳齿被当成细节保留；性能档直接丢弃一场，运动分辨率减半。media/deinterlace_ivtc.py 是核心，tests/test_deinterlace_ivtc.py 15个红。要修的是：场序用多帧统计判定；动检按局部对比度自适应；cadence 用 3:2 序列匹配；字幕台标走静态保护；时间戳按素材时基重排；10bit 全链路；切镜重置动检；预览导出统一场序；去隔行后再降噪；降级做场混合不丢场。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
